# Generated results

This directory contains no prefilled or synthetic result. GitHub Actions generates simulation logs, JUnit XML, Verilator lint logs, Yosys logs and netlists, source-hashed JSON summaries, generic configuration comparisons, and Markdown reports.

Until those workflows run, status is **pending**. Generated outputs are excluded from Git so a passing result cannot be implied by the presence of a source file. Retain the workflow artifacts with their commit SHA and toolchain lock.
